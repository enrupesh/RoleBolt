UI/UX Polish Brief (Claude/ChatGPT Level Experience)

We've completed the core functionality. From this point onward, I want to focus entirely on UI/UX polish.

The current interface feels functional but not premium. I want the experience to feel closer to ChatGPT / Claude, while still maintaining Rolebolt's own identity.

Overall Design Direction
Modern
Minimal
Premium
Spacious
AI-first
Recruiter-focused

Use a soft light theme, not the current dark interface.

Theme

Background:

#FBFBFB

Cards:

#FFFFFF

Border:

#E5E7EB

Primary Accent (keep existing purple):

#6D5DF6

Text:

#111827

Secondary Text:

#6B7280

Rounded corners:

16px–20px

Soft shadows only.

Avoid heavy borders and dark blocks.

Chat Experience

The chat should feel much closer to Claude.

Instead of plain text floating on the page:

Every AI response should appear inside a beautiful rounded message card.

Example:

╭──────────────────────────────╮
│ ✨ ROLEBOLT AI               │
│                              │
│ Rahul Sharma is currently    │
│ the strongest candidate...   │
│                              │
│ Recommendation               │
│ Interview Rahul first        │
│                              │
│ Sources                      │
│ Resume • Assessment          │
╰──────────────────────────────╯

User messages should also appear in separate bubbles.

Messages should never blend into the page background.

Input Experience

Currently after sending a message, I have to click the textbox again before typing.

Please fix this.

Requirements:

Automatically keep focus on the input after sending.
Press Enter to send.
Shift+Enter for newline.
Cursor should remain active after every response.
The user should be able to continuously chat without touching the mouse.
Layout Improvements

Increase whitespace.

Reduce visual clutter.

Better spacing between:

messages
cards
panels
sections

Everything should breathe.

Candidate Identity

Whenever AI mentions a candidate, display a small identity card.

Example:

⭐ 94 Fit Score

This should be visually separated from the response.

Loading Experience

Streaming should look premium.

Show:

"Analyzing resumes..."

"Comparing candidates..."

"Generating recommendation..."

instead of a blank waiting state.

Animations

Use subtle animations only.

Fade in messages
Smooth panel transitions
Hover effects
Button elevation
Skeleton loading

No flashy animations.

Responsive Layout

The application should work well on:

Laptop
Desktop
Tablet
Overall Goal

I don't want it to feel like a CRUD dashboard.

I want it to feel like a premium AI product.

When someone opens Ask Rolebolt, the first impression should be:

"This feels like ChatGPT or Claude, but built specifically for hiring."

Please prioritize polish, consistency, spacing, typography, and interaction quality over adding new features.
