Please add a new **AI Agent Stats** section to the Job page to give recruiters a quick overview of the AI Agent's performance.

## Feature Name

**AI Agent Stats** (or **AI Agent Insights**)

## Placement

Display this as a compact stats card in the **Job Header** or **Performance** tab.

## Metrics to Display

**AI Agent — This Week**

* ✅ Shortlisted
* ❌ Rejected
* ⏳ In Review
* 📧 Emails Sent
* ⚡ Average AI Score

Example:

```
AI Agent — This Week

✅ 8 Shortlisted
❌ 3 Rejected
⏳ 5 In Review

📧 11 Emails Sent
⚡ Avg Score: 71%
```

## Data Requirements

The stats should automatically update based on AI Agent activity for the selected time period.

Track:

* Total candidates processed
* Number shortlisted
* Number rejected
* Number placed in Review
* Total automated emails sent (shortlist, review, rejection, assessment)
* Average AI score of processed candidates

## Time Filter

Support:

* Today
* This Week (default)
* This Month
* All Time

## UI Requirements

* Show loading and empty states.
* Clicking any metric should open the filtered candidate list (e.g., clicking **Shortlisted** opens all shortlisted candidates for that period).
* Refresh automatically when the AI Agent processes new candidates.

## AI Insights

Below the stats, display simple AI-generated recommendations based on current performance.

Examples:

* "82% of candidates are in the Review zone. Consider adjusting your shortlist threshold."
* "Very few candidates are being shortlisted. Your scoring criteria may be too strict."
* "Most candidates are being shortlisted. Consider increasing the shortlist threshold."

## Acceptance Criteria

1. Add an **AI Agent Stats** card to the Job page.
2. Display real-time statistics for the selected time period.
3. Keep the statistics synchronized with AI Agent actions.
4. Support clickable metrics for quick filtering.
5. Show AI-generated recommendations based on the statistics.
6. Ensure the feature is lightweight and does not impact page performance.

This feature should help recruiters instantly understand how the AI Agent is performing and whether scoring thresholds or hiring rules need adjustment, without opening individual candidate profiles.
