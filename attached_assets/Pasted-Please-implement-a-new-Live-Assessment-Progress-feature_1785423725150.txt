Please implement a new **Live Assessment Progress** feature for the recruiter dashboard.

## Objective

Provide recruiters with real-time visibility into the progress of candidates who are currently taking assessments, allowing them to monitor assessment activity without opening individual candidate profiles.

## Feature Requirements

### Live Assessment Status

Display a dedicated **Live Assessment Progress** panel showing all candidates with assessments that are currently in progress.

For each candidate, display:

* Candidate Name
* Job Title
* Assessment Status
* Current Question (e.g., Question 3 of 5)
* Assessment Progress (%)
* Time Elapsed
* Assessment Start Time
* Remaining Time (if the assessment is timed)

Example:

* Rahul Sharma — Question 3 of 5 — 60% Complete — 14 minutes elapsed
* Priya Singh — Question 5 of 5 — 95% Complete — 22 minutes elapsed

---

## Real-Time Updates

The dashboard should update automatically as candidates progress through the assessment.

Track events such as:

* Assessment Started
* Current Question Changed
* Progress Percentage Updated
* Assessment Submitted
* Assessment Expired (if time limit is reached)

Recruiters should not need to refresh the page to see updated progress.

---

## Dashboard Summary

Display live statistics, including:

* Assessments Currently In Progress
* Assessments Completed Today
* Assessments Pending
* Average Completion Time
* Average Current Progress

---

## Candidate Actions

Recruiters should be able to click a candidate to view:

* Assessment details
* Current progress
* Start time
* Time spent
* Final results (after submission)

Recruiters must **not** be able to see the candidate's answers while the assessment is still in progress to preserve assessment integrity.

---

## Activity Feed

Record all major assessment events:

* Assessment Started
* Assessment Submitted
* Assessment Timed Out
* Assessment Completed

Include timestamps for every event.

---

## Acceptance Criteria

1. Display all active assessments in a dedicated Live Assessment Progress panel.
2. Show real-time progress, current question, elapsed time, and completion percentage.
3. Automatically update progress without requiring a page refresh.
4. Prevent recruiters from viewing candidate answers until the assessment is submitted.
5. Keep all live metrics synchronized with the assessment engine.
6. Record all assessment lifecycle events in the Activity Feed and Audit Log.

This feature will give recruiters real-time visibility into ongoing assessments, improve monitoring, and provide a more transparent assessment experience while maintaining assessment security.
